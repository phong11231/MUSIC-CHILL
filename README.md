# MUSIC-CHILL

Trang web phát nhạc SoundCloud theo đoạn.

- Dán link SoundCloud, đặt **Start → End** cho từng link.
- **Lặp danh sách**: phát hết đoạn thì chuyển sang link tiếp theo, hết danh sách thì quay lại link đầu.
- **Lặp 1 bài**: phát hết đoạn thì quay lại Start của chính link đó.
- Nền trang lấy từ ảnh bìa bài đang phát.
- Link hỏng hoặc bị để riêng tư sẽ tự được bỏ qua.
- Danh sách lưu trong trình duyệt (localStorage).

Chỉ có một file `index.html`, không cần build. Có thể bật GitHub Pages để lấy link web.
